Fresh 12-case CIMET/OC measurement pilot.

and computes OC using the pinned upstream pair formula with half-open weeks
and full-email identity hashes. It retains upstream symmetric aggregation and
an explicit distinct-pair mean as separate columns. Two active-era cases have
additional historical snapshots.

use the anchor snapshot map as a provisional comparator and author timestamps
for compatibility. These pilot tables must not be labeled primary study data.

metric status. It retains the upstream aggregate separately. JUnit RELEASE is
replaced with 5.10.2 for a reproducible build. The Maven upstream test suite is
not claimed to have run; explicit study adapter fixtures run before case jobs.
